# CIS-116-Project
CIS 116 Zombie Game Program

What the Project Does:
Our project is called Apocalypse Loadout Builder. It is a simple program where users can get ready for a made-up disaster, like a zombie outbreak or being stuck in the wilderness. Users pick supplies they want to bring, but they have to stay under a weight limit and certain specifications. The program is mainly for people who like survival games and want to see how prepared they would be.


How It Will Work:
The users will see a start menu. They can look at supplies, add or remove preloaded items from their loadout, (possibly) pick multiple different disaster scenarios, check their survival score, or save and load a loadout. The program will show the user's items, total weight, and score. Users can keep making changes or can choose to exit. 


Main Features:
We plan to make a supply list with each item's name, weight, and category. Users can build a loadout by adding and removing items, but they cannot go over the weight limit. They can also choose a scenario, such as a zombie outbreak, nuclear fallout, or wilderness survival. Each scenario will value supplies a little differently. Finally, the program will give the loadout a score based on things like food, water, medical supplies, and shelter. Users will be able to save their loadouts and open them again later. If we have time, we may add more items, scenarios, and places to spawn.
